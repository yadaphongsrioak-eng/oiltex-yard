# OIL-TEX Yard Access — เว็บแอปลงทะเบียนเข้า–ออก

เปิดในเว็บเบราว์เซอร์ของมือถือหรือแท็บเล็ตได้เลย (Chrome / Safari) ไม่ต้องติดตั้งแอป ไม่ต้องล็อกอิน
อ่านป้ายทะเบียน บัตรประชาชน ใบขับขี่ พาสปอร์ต และ QR **ด้วยกล้องสดแบบเรียลไทม์** ประมวลผลในเครื่องทั้งหมด ใช้ได้แม้เน็ตหลุด

## ต้องเปิดผ่านลิงก์ https

เบราว์เซอร์อนุญาตให้ใช้กล้องสดเฉพาะเว็บที่เป็น https เท่านั้น ให้นำโฟลเดอร์นี้ขึ้นเว็บฟรีวิธีใดวิธีหนึ่ง

**วิธีที่ง่ายที่สุด: Netlify (ฟรี)**
1. แตกไฟล์ zip จะได้โฟลเดอร์ `oiltex-yard-web`
2. เปิด https://app.netlify.com/drop บนคอมพิวเตอร์ แล้วสมัครฟรีด้วยอีเมลหรือ Google
3. ลากโฟลเดอร์ `oiltex-yard-web` ทั้งโฟลเดอร์ไปวางในหน้านั้น
4. จะได้ลิงก์ เช่น `https://ชื่อสุ่ม.netlify.app` เปลี่ยนชื่อได้ที่ Site configuration > Change site name เช่น `oiltex-yard.netlify.app`

**ทางเลือกอื่น:** Cloudflare Pages (Upload assets) หรือ GitHub Pages ก็ใช้ได้เหมือนกัน

## ใช้งานครั้งแรกที่ป้อม รปภ.

1. เปิดลิงก์ในมือถือ/แท็บเล็ต แล้วไปที่แท็บ **QR/ตั้งค่า**
2. กด **พิมพ์โปสเตอร์ QR** ติดที่ป้อม เครื่องอื่นสแกนเปิดได้ทันที
3. ตั้ง **ชื่อจุดตรวจ** ของเครื่อง และใส่รายชื่อบริษัทผู้เช่า
4. เพิ่มไว้ที่หน้าจอหลัก (Chrome: ⋮ > เพิ่มลงในหน้าจอหลัก · Safari: แชร์ > เพิ่มไปยังหน้าจอโฮม) จะเปิดเหมือนแอป
5. ครั้งแรกที่กดสแกน เบราว์เซอร์จะถามสิทธิ์กล้อง ให้กด **อนุญาต**

## วิธีสแกนให้ติดเร็ว

- **ป้ายทะเบียน:** ให้ป้ายเต็มกรอบ ถือนิ่ง 1–2 วินาที ระบบล็อกเมื่ออ่านตรงกัน 3 ครั้ง (รถที่เคยเข้าแล้ว 2 ครั้ง) รถอยู่ไกลใช้แถบ **ซูม** กลางคืนกด **ไฟ**
- **บัตรประชาชน / ใบขับขี่:** วางด้านหน้าบัตรให้เต็มกรอบ เลขบัตร 13 หลักต้องผ่านการตรวจเลขก่อนจึงจะล็อก ชื่ออ่านจากบัตร ถ้าไม่ชัดจะใช้ชื่อภาษาอังกฤษ แก้ได้
- **พาสปอร์ต:** ให้แถบตัวอักษร 2 บรรทัดล่าง (MRZ) อยู่ในกรอบเส้นประ ระบบตรวจตัวเลขตรวจสอบ 3 จุด
- **QR บัตรผ่าน:** ล็อกทันที ถ้ารายการนั้นอยู่ในพื้นที่จะพาไปปุ่มบันทึกออก

สแกนป้ายรถที่อยู่ในพื้นที่แล้ว จะมีปุ่ม **บันทึกออกเลย** ให้กดได้จากหน้ากล้อง

## ข้อมูลเก็บที่ไหน

- เก็บในเบราว์เซอร์ของเครื่องนั้น (IndexedDB) ไม่ส่งไปที่อื่น
- เก็บเลขบัตรเฉพาะ 4 หลักท้าย ไม่เก็บรูปถ่าย (ตาม PDPA)
- **สำรองข้อมูลทุกสัปดาห์:** แท็บ QR/ตั้งค่า > สำรองข้อมูล (.json) ถ้าล้างข้อมูลเบราว์เซอร์หรือเปลี่ยนเครื่อง ใช้ "นำเข้าไฟล์สำรอง"
- รายงานส่งออกเป็น CSV เปิดด้วย Excel ได้ภาษาไทยถูกต้อง

## ใช้หลายเครื่อง / ให้หลังบ้านดูจากที่อื่น (ไม่บังคับ)

แต่ละเครื่องเก็บข้อมูลของตัวเอง ถ้าต้องการรวมทุกจุดตรวจไว้ที่เดียว ให้ส่งขึ้น Google Sheets
1. เปิดไฟล์ `google-apps-script.gs` ทำตามขั้นตอนด้านบนของไฟล์ (ใช้เวลาประมาณ 5 นาที)
2. วางลิงก์ `/exec` ในแอปทุกเครื่อง: แท็บ QR/ตั้งค่า > ส่งข้อมูลขึ้น Google Sheets > บันทึกและทดสอบ
3. ทุกการเข้า–ออกจะขึ้นชีตอัตโนมัติ ถ้าเน็ตหลุดจะเก็บไว้ส่งเมื่อกลับมาออนไลน์

## อัปเดตเวอร์ชัน

อัปโหลดไฟล์ใหม่ทับของเดิมบนเว็บ แล้วแก้บรรทัด `VERSION` ใน `sw.js` (เช่น v1 เป็น v2) เพื่อให้ทุกเครื่องโหลดไฟล์ใหม่

## ไฟล์ในโฟลเดอร์

- `index.html`, `app.js` — หน้าจอและการทำงานของแอป
- `ocr.js` — ตัวอ่านป้าย/บัตร (ตรวจรูปแบบทะเบียน, 77 จังหวัด, เลขบัตร 13 หลัก, MRZ)
- `vendor/` — ตัวอ่านตัวอักษร Tesseract ภาษาไทย/อังกฤษ, ตัวอ่าน/สร้าง QR, ฟอนต์ (ทำงานออฟไลน์)
- `sw.js`, `manifest.webmanifest`, `icon-*.png` — ให้ติดตั้งเป็นแอปและเปิดออฟไลน์ได้
- `google-apps-script.gs` — โค้ดสำหรับส่งข้อมูลขึ้น Google Sheets
